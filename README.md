### 🔬 What I'm working on

I work on **inference optimization and efficient training** for language models. I'm interested in closing the gap between capable models and AI systems that are practical to deploy.

- **Efficient generation** — diffusion models, speculative decoding, and distillation.
- **Scalable AI systems** — efficient inference for agentic workflows and synthetic data generation.
